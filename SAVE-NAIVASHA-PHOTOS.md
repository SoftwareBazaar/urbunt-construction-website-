## Add Watermark Options:

### Option 1: Online (Easiest - 5 minutes)
**Website:** https://watermarkly.com/add-watermark/

**Steps:**
1. Click "Add Photos" → select all 6 images
2. Click "Add Watermark" → "Text"
3. Type: **Urban T Construction**
4. Settings:
   - Position: Bottom right
   - Font: Bold
   - Size: 40
   - Color: White
   - Add shadow: Yes (black, 70% opacity)
5. Click "Download All"
6. Save to: `Desktop/naivasha-watermarked/`

### Option 2: Canva (Professional - 10 minutes)
**Website:** https://www.canva.com/ (free account)

**For each photo:**
1. Upload photo as background
2. Add text element: "Urban T Construction"
3. Style with white text + black drop shadow
4. Position bottom right
5. Download as high-quality JPG

### Option 3: Photoshop/GIMP (If you have it)
- Add text layer: "Urban T Construction"
- White text (#FFFFFF)
- Drop shadow: 5px blur, black 70% opacity
- Position: Bottom right corner, 30px margin
