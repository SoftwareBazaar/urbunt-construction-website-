# 🎨 How to Add Your Logo and Video

## 📁 File Locations

### Logo
Save your logo file as:
```
buildcraftandco-main/public/urban-t-logo.png
```

**Requirements:**
- Format: PNG (transparent background recommended)
- Recommended size: 256x256 pixels or larger
- Max file size: 500 KB

### Hero Background Video
Save your video file as:
```
buildcraftandco-main/public/urban-t-hero.webm
```
OR
```
buildcraftandco-main/public/urban-t-hero.mp4
```

**Requirements:**
- Format: WebM or MP4 (WebM preferred for web)
- Recommended resolution: 1920x1080 (Full HD)
- Duration: 10-30 seconds (will loop)
- Max file size: 10 MB (smaller is better for load times)

---

## 🚀 After Adding Files

1. **Copy your files** to the locations above
2. **Commit and push** to GitHub:
   ```powershell
   cd "buildcraftandco-main"
   git add public/
   git commit -m "Add logo and hero video"
   git push
   ```
3. **Vercel will automatically redeploy** (2-3 minutes)
4. Your logo and video will appear on the live site!

## 🎬 Where to Get a Video

If you don't have a hero video yet, you can:

1. **Hire a videographer** to film your construction sites
2. **Use stock footage** from:
   - Pexels Videos (free): https://www.pexels.com/search/videos/construction/
   - Unsplash Videos (free): https://unsplash.com/s/videos/construction
   - Envato Elements (paid): https://elements.envato.com/

3. **Create a slideshow** from your project photos using:
   - Canva (free): https://www.canva.com/
   - Adobe Express (free): https://www.adobe.com/express/

## 🖼️ Where to Get/Create a Logo

If you need a logo:

1. **Hire a designer** on Fiverr or Upwork
